# Бот ВКонтакте на vkbottle

Асинхронный бот (asyncio + [vkbottle](https://github.com/vkbottle/vkbottle)) для сообщества ВКонтакте.
С ним можно общаться в приложении ВК на телефоне, на vk.com в браузере.

## Что умеет бот

| Команда / кнопка | Что делает |
|---|---|
| `/start` или «Начать» | Приветствие + inline-меню «Расписание» / «Помощь» |
| `/help` или «Помощь» | Список доступных команд |
| `/schedule`, «Расписание» или «Когда занятия?» | Запускает сценарий «Расписание» |
| «Отмена» (во время выбора группы) | Выход из сценария |
| Всё остальное | Подсказка написать «Помощь» |

### Сценарий «Расписание»

```
Пользователь: Расписание
Бот:          Выберите номер группы на клавиатуре (101, 102 или 103).
              [101] [102] [103]
              [Отмена]
Пользователь: (нажимает 102)
Бот:          Расписание для группы 102: вторник/четверг 11:00–14:00.
              [Расписание]
              [Помощь]
```

- После «Расписание» бот запоминает состояние `ScheduleState.WAITING_GROUP` для этого пользователя.
- В этом состоянии любое сообщение считается номером группы. Неизвестный номер → «Группа не найдена» и клавиатура выбора снова; состояние сохраняется.
- Верный номер или «Отмена» → состояние сбрасывается. `/start` тоже сбрасывает сценарий.

Все кнопки — inline (прикреплены к сообщению). Кнопка отправляет свою подпись как обычный текст, поэтому её ловят те же обработчики `text=...`, что и ввод вручную. Регистр не важен.

## Структура

```
prj2/
├── bot.py               # точка входа: создаёт Bot, подключает обработчики, запускает Long Poll
├── config.py            # чтение .env (VK_TOKEN, VK_GROUP_ID, SITE_HOST, SITE_PORT)
├── handlers/
│   ├── __init__.py      # список labeler'ов в порядке приоритета
│   ├── start.py         # /start, «Начать»
│   ├── help.py          # /help, «Помощь»
│   ├── schedule.py      # сценарий «Расписание» с состояниями
│   └── fallback.py      # ответ на неизвестные сообщения
├── keyboards.py         # inline-клавиатуры: главное меню и выбор группы
├── states.py            # ScheduleState и общее хранилище состояний (в памяти)
├── schedule_data.py     # расписание групп
├── texts.py             # тексты сообщений и подписи кнопок
├── site/index.html      # страница сайта с виджетом сообщений VK
├── serve_site.py        # локальный сервер страницы (подставляет ID сообщества)
├── tests/test_bot.py    # тесты маршрутизации без настоящего VK API
├── requirements.txt
├── pytest.ini
└── .env.example
```

Обработчики объявлены декораторами `@labeler.message(command="start")` и
`@labeler.message(text="Начать")`. Два декоратора на одной функции означают «или»: сработает любой. В vkbottle 4 параметр называется `command` (одна команда, префиксы `/` и `!`), а не `commands=[...]`.

## 1. Настройка сообщества ВКонтакте

1. Создайте сообщество: <https://vk.com/groups> → «Создать сообщество».
2. **Управление → Сообщения**: включите «Сообщения сообщества».
3. **Управление → Сообщения → Настройки для бота**:
   - включите «Возможности ботов» — без этого клавиатуры не отправляются;
   - включите «Добавить кнопку „Начать“» — новый пользователь увидит её в пустом диалоге.
4. **Управление → Дополнительно → Работа с API → Ключи доступа → Создать ключ**. Отметьте права:
   - «Сообщения сообщества» — отправка сообщений и клавиатур;
   - «Управление сообществом» — нужно для Long Poll.

   Скопируйте ключ — это `VK_TOKEN`.
 
5. **Управление → Работа с API → Long Poll API**: включите Long Poll, выберите последнюю версию API, на вкладке «Типы событий» отметьте «Входящее сообщение».
6. ID сообщества — цифры из адреса `vk.com/club123456789` (или в «Управление → Адрес»).
   Это `VK_GROUP_ID`. 

**Проверка прав.** Если бот получает сообщения, но не отвечает, в консоли будет ошибка VK API:
`[15] Access denied` / `[27] Group authorization failed` — у ключа нет нужных прав;
`[901] Can't send messages` — пользователь запретил сообщения от сообщества
(нужно сначала написать боту самому); клавиатура не появляется — выключены «Возможности ботов».

## 2. Ссылка на бота

```
https://vk.me/club<VK_GROUP_ID>

```

Например, `https://vk.me/club123456789`. Если у сообщества задан короткий адрес —
`https://vk.me/<короткий_адрес>`.

- На телефоне ссылка открывает диалог с ботом в приложении ВКонтакте.
- В браузере — диалог на vk.com.
- Ещё вариант — кнопка «Написать сообщение» на странице сообщества.

## 3. Установка

Нужен Python 3.10+.

```bash
cd prj2 (Перейдите в папку с ботом)
```

```bash
python3 -m venv .venv
```

```bash
source .venv/bin/activate 
или 
.venv\Scripts\activate (если командная строка Windows)
```

```bash
pip install -r requirements.txt
```

```bash
cp .env.example .env (или переименуйте файл сами)
```

Откройте `.env` и впишите `VK_TOKEN` и `VK_GROUP_ID`. Файл `.env` в git не попадает.

## 4. Запуск бота

```bash
python bot.py
```

Бот подключается к ВК через Long Poll: публичный адрес и HTTPS не нужны, достаточно запустить
на своём компьютере. Напишите сообществу `/start` или нажмите «Начать». Остановка — `Ctrl+C`.

## 5. Бот на сайте

На сайт бот встраивается виджетом «Сообщения сообщества». Он показывает в углу страницы
кнопку, по которой открывается диалог с сообществом — тот же диалог, что и во ВКонтакте, поэтому отвечает тот же запущенный `bot.py`. Посетитель должен быть авторизован во ВКонтакте (виджет сам предложит войти).

### Посмотреть локально

Бот должен быть запущен (`python bot.py`), а в отдельном терминале:

```bash
python serve_site.py
```

Откройте <http://127.0.0.1:8080>. Скрипт подставляет `VK_GROUP_ID` из `.env` в
`site/index.html`. Страницу нужно открывать именно по `http://`, а не как файл (`file://`): виджет VK не работает с локальными файлами.

### Встроить на свой сайт

Вставьте в HTML страницы перед `</body>`, заменив `123456789` на ID своего сообщества:

```html
<script src="https://vk.com/js/api/openapi.js?169"></script>
<div id="vk_community_messages"></div>
<script>
  VK.Widgets.CommunityMessages("vk_community_messages", 123456789, {
    tooltipButtonText: "Спросить расписание"
  });
</script>
```

Можно также просто поставить ссылку-кнопку на `https://vk.me/club123456789`.
Готовую страницу можно выложить на любой хостинг статических сайтов (например, GitHub Pages): скопируйте `site/index.html` и замените в нём `{{GROUP_ID}}` на ID сообщества.

Тесты прогоняют события `message_new` через роутер vkbottle с подменённым VK API и проверяют ответы, клавиатуры и состояния.

## Примечания

- Состояния хранятся в памяти (`BuiltinStateDispenser`) и сбрасываются при перезапуске бота.
- Inline-клавиатуры поддерживаются в актуальных приложениях ВК, на vk.com и в виджете на сайте.
